## 2. 最终模型与结果

**模型:** 一个**由五个差异化模型组成的等权概率集成** —— LightGBM · 逻辑回归 · MLP · KNN ·
CatBoost —— 外包一层**生物硬约束解码器**与**折内安全的 target encoding**,并刻意
**不含任何实验特有 ID**。

**我们为什么这么选:**
- **多样性胜过单个调优模型** —— 五个犯错方式互不相关的模型取平均,比其中任何一个都更稳。
- **生物规律应当被强制,而非仅靠学习** —— 一个细胞不可能既是兴奋性又是抑制性类型,所以我们
  直接禁止模型跨越这条界线。
- **诚实的泛化胜过榜单分数** —— 我们用留出整只小鼠的方式验证,并把实验 ID 排除在特征之外,
  因为随机交叉验证会误导(见下)。

**结果** —— 留一小鼠准确率(诚实的、按组验证的指标):

| 模型 | 留一小鼠准确率 |
|---|---|
| KNN | 0.688 |
| MLP | 0.734 |
| 逻辑回归 | 0.735 |
| CatBoost | 0.743 |
| LightGBM(基线) | 0.760 |
| **五模型集成(最终)** | **0.769** |

## 3. 对模型提升最大的因素

真正起作用的是三点:

- **生物约束解码。** EDA 显示*兴奋性 / 抑制性 / 非神经元*三组**从不共享任何细胞类型**,于是用
  硬掩码禁止预测跨越自己的 E/I 组——一整类错误免费消除。
- **折内安全的 target encoding。** 把解剖分组(Region、Segment 及其与 E/I 的联合)编码成折外的
  每组细胞类型先验——一个 200 个稀疏基因给不出的"这里住着谁"的信号。这是最有效的单个特征。
- **泛化优先的验证。** 我们用**留一小鼠**和**留一批次** GroupKFold 验证,并把 Mouse / Section /
  Dataset 排除在特征外。这很关键:早期版本在随机 CV 上约 0.777,线上却只有约 0.75——约 0.02 的
  差距来自随机 CV 的乐观 + ID 类拐杖。去掉 ID、按组验证,把这个差距补上了。
  *(我们采用的经验法则:一个改动只有在两个 seed 上同号才算数。)*

## 4. 我们如何一步步搭起模型

1. **基线 —— LightGBM。** 表格数据上又强又快,作为起点。
2. **加线性模型 —— 逻辑回归。** 只有 5K 细胞、200 个极稀疏基因(约 93% 为 0)时,线性模型擅长
   稀疏高维数据,*而且*犯错方式和树不同——这是第一重多样性来源。
3. **再加三个差异化模型。** **MLP** 抓非线性结构、**KNN** 用表达空间的邻域信号、**CatBoost** ——
   同是树,但和 LightGBM 行为略有区别。
4. **以概率平均融合。** 简单而稳健。相比特征工程后的最佳单模型,集成带来了约**一个点**的提升——
   完全来自多样性:各模型犯的错不同,取平均就互相抵消。

## 5. 值得进一步探索的方向

这些想法在 5K 细胞上表现一般,但属于**受验证/数据量限制,而非错误**——这个领域的真实问题可达
10⁵–10⁶ 细胞。详见 [`reports/lessons_learned.md`](reports/lessons_learned.md)。

- **表达标签特征**(类质心余弦 + 表达 kNN 投票)—— 5K 下噪声大,参照细胞一多就稳。
- **解剖桶约束**(Region×E/I×Segment;28 个桶里 15 个只对应一种类型)—— 覆盖度补齐后,是 E/I
  掩码的精细升级版。
- **深度 & 空间模型**(CNN/DNN、整切片半监督)—— 吃数据;规模上去应反超。
- **LLM 重排(Qwen)**—— 只在自己模型不确定的 top-3 里、凭 marker 基因证据重排;仅研究,从未提交。

**天花板是数据而非方法的证据:** 在一个更大的*公开*图谱上、整只小鼠留出,同一套流程随标注细胞
5K→118K 从约 0.77 提升到约 **0.92**。一个我踩过的坑——**要看 fold 方差,而不只是均值**:欠正则的
模型会把整只留出小鼠悄悄塌陷到 0.06,而随机 CV 还显示 0.9。
代码:[`experiments/atlas_loso_testbed.py`](experiments/atlas_loso_testbed.py)。
