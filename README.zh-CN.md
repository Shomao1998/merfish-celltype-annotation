# MERFISH 空间转录组 — 细胞类型注释

**[English](README.md) | 中文**

> 从稀疏的空间基因表达中,区分 60 种神经元细胞类型。
> **🥈 罗切斯特大学生物医学数据科学黑客松 2026 夏 · 二等奖**(团队 **XDRKAMOA**)。

本仓库是我在团队二等奖作品中**负责的建模线**,外加驱动我们决策的验证框架,以及一项探讨"如何把模型推得更远"的赛后研究。整条线的重点是**诚实的泛化能力**,而不是刷榜。

---

## 一句话总览

- **任务:** 为小鼠脊髓 **MERFISH** 数据中的每个细胞预测细胞类型(60 选 1)——约 10,000 个细胞、**200 个基因**、约 **93% 是 0**。指标:整体准确率。
- **有效的东西:** 一个**带生物约束的五模型概率集成**,配合折内安全的 **target encoding**,用**留一小鼠** GroupKFold 验证。
- **最有意思的部分:** 我诊断出一个 **~0.02 的 CV→线上榜单差距**(随机 CV 过于乐观),把模型重建为**去 ID、按组验证**;随后做了一项**赛后规模化研究**,证明真正的天花板是**数据,而非方法**(留一小鼠准确率随标注细胞 5K→118K 从 **0.77 提升到 0.92**)。
- **诚信:** 提交模型使用**零外部数据**。我还发现(且未利用)一个榜单**数据泄漏**——公开的源图谱包含了测试细胞。

---

## 结果

留一小鼠准确率(诚实的、按组验证的指标):

| 模型 | 留一小鼠准确率 |
|---|---|
| KNN | 0.688 |
| MLP | 0.734 |
| 逻辑回归 | 0.735 |
| CatBoost | 0.743 |
| LightGBM(基线) | 0.760 |
| **五模型集成(最终)** | **0.769** |

![集成 vs 单模型](reports/figures/ensemble_vs_single.png)

提升不大但真实,而且完全来自**多样性**——五个犯错方式互不相关的模型,取平均后互相抵消。

---

## 方法

**基线 → 集成。** 我从 **LightGBM** 起步(表格数据上很强)。因为数据只有 5K 细胞、200 个极稀疏基因,我加了**逻辑回归**(线性模型擅长稀疏高维、且和树犯错方式不同),再融合 **MLP**(非线性结构)、**KNN**(邻域信号)、**CatBoost**(行为略有区别的另一棵树)。五者以**等权概率平均**融合。

**生物约束解码。** EDA 显示*兴奋性 / 抑制性 / 非神经元*三组**从不共享任何细胞类型**,于是用硬掩码禁止预测跨越自己的 E/I 组——一整类错误免费消除。

**折内安全的 target encoding。** 把解剖分组(Region、Segment 及其与 E/I 的联合)编码成每组的细胞类型先验——一个折外的"这里住着谁"的信号,是 200 个稀疏基因单独给不出的。这是最有效的单个特征。

**泛化优先的设计。** 实验特有 ID(Mouse / Section / Dataset)**不进特征**,只用于分组验证。

---

## 为什么它足够严谨(我最自豪的部分)

- **双 seed 纪律** —— 一个改动只有在两个 seed 上同号才算数(噪声地板 ≈ ±0.005)。
- **留一小鼠 & 留一批次 GroupKFold** —— 模拟真正意义上的新动物/新实验。随机 CV 会在训练与验证间共享切片,过于乐观。
- **CV→榜单差距,已诊断并修复。** 早期版本在随机 CV 上约 0.777,线上却只有约 0.75。原因是随机 CV 的乐观 + ID 类拐杖;修复方式就是上面的去 ID、按组验证设计。

---

## 赛后研究:天花板是数据,不是方法

把一个更大的**公开**脊髓 MERFISH 图谱(约 147K 细胞、10 只小鼠)**纯粹当作规模化试验台**——**整只小鼠留出**,保证被留出细胞的邻居绝不出现在训练里——同一套流程在标注细胞 5K→118K 时,留一小鼠准确率从约 0.77 提升到约 **0.92**。

![数据规模](reports/figures/data_scaling.png)

一个我踩过的坑:**欠正则的 GBDT 会把整只留出小鼠悄悄塌陷**到约 0.06 的准确率,而随机 CV 还显示约 0.9。**要看 fold 方差,而不只是均值。** 代码:[`experiments/atlas_loso_testbed.py`](experiments/atlas_loso_testbed.py)。

**这正是为什么我们舍弃的几个方向是"受验证/数据量限制",而非错误** —— 见 [`reports/lessons_learned.md`](reports/lessons_learned.md)。

## 诚信说明

比赛禁止外部数据。我们的**提交模型完全没用**。比赛期间我发现公开源图谱(Zenodo `MERFISH_spinal_cord_resolved_0718`)**包含比赛自己的细胞**,标签可被还原——这是真实的榜单泄漏。我们**没有利用它**;本仓库**不含任何还原答案的代码**。图谱在这里只作为*赛后*规模化试验台(整只小鼠留出),而任何 LLM 组件(见下)都仅作**研究用途、从未提交**,因为预训练模型的知识本身可能算作外部信息。

## 复现

```bash
pip install -r requirements.txt
# 本仓库不重新分发数据 —— 获取方式见 data/README.md,准备好后:
python src/model_v031_robust_5model.py --mode oof   --schemes mouse dataset --seeds 0 1   # 按组 CV
python src/model_v031_robust_5model.py --mode predict --seeds 0 1 2 3 4                    # 生成提交
# 赛后规模化研究(需要公开图谱 —— 见 data/README.md):
python experiments/atlas_loso_testbed.py --mode dev
```
